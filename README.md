# Stickman Ragdoll — راهنمای ساخت APK فقط با گوشی

این پروژه یه اپ HTML5/JS هست که با **Capacitor** به یه اپ اندروید واقعی تبدیل میشه، و کامپایلش کاملاً روی سرورهای گیت‌هاب (GitHub Actions) انجام میشه — نیازی به کامپیوتر نیست.

## چی داخلشه؟
- `www/` — کد اصلی اپ (HTML/CSS/JS): فیزیک راگدال با روش Verlet، منوی Emote/Dance/Pose/Options، اسلایدر تعداد آدمک‌ها، دکمه‌ی Never Touch، و پخش موزیک از فایل‌های خود گوشی با هماهنگی حرکت به بیت آهنگ.
- `.github/workflows/build-apk.yml` — وقتی پوش کنی، خودکار APK می‌سازه.
- `package.json` و `capacitor.config.json` — تنظیمات Capacitor.

## مراحل (همه از توی اپ GitHub یا مرورگر گوشی):

1. **ساخت ریپازیتوری:** توی اپ یا سایت گیت‌هاب یه ریپازیتوری جدید (Public یا Private) بساز، مثلاً به اسم `stickman-ragdoll`.

2. **آپلود فایل‌ها:** تمام فایل‌ها و پوشه‌های این پروژه رو (با همین ساختار پوشه‌ای — خیلی مهمه که `.github/workflows/build-apk.yml` دقیقاً همون آدرس رو داشته باشه) توی اون ریپو آپلود کن. توی اپ گیت‌هاب گزینه‌ی «Add file → Upload files» رو بزن و فایل‌ها رو بکش داخلش. برای پوشه‌ها، آدرس مسیر رو موقع آپلود حفظ کن (گیت‌هاب معمولاً وقتی یه پوشه رو درگ کنی مسیرش رو خودش می‌سازه).

3. **اجرای Build:** بعد از آپلود (push به شاخه‌ی `main`)، برو به تب **Actions** توی ریپو. یه Workflow به اسم «Build APK» خودش شروع میشه. چند دقیقه صبر کن تا تیک سبز بخوره (ممکنه ۵ تا ۱۰ دقیقه طول بکشه).

4. **دانلود APK:** روی همون اجرای موفق (workflow run) بزن، پایین صفحه بخش **Artifacts** رو ببین، فایل `stickman-ragdoll-debug-apk` رو دانلود کن — یه zip هست که داخلش `app-debug.apk` هست.

5. **نصب روی گوشی:** فایل apk رو از حالت zip خارج کن و نصبش کن (باید اجازه‌ی «نصب از منابع ناشناس» رو بدی).

## نکته‌ها
- این نسخه **Debug** هست (بدون امضای رسمی) — برای تست شخصی مشکلی نداره، ولی برای انتشار در Google Play باید بعداً امضا (signing) اضافه بشه که یه مرحله‌ی جداست.
- برای موزیک، اپ از انتخابگر فایل خود اندروید استفاده می‌کنه (دکمه‌ی «Choose Music From Device» توی تب Options) پس نیازی به مجوز خاص اضافه‌ای نداره.
- اگه خواستی اسم اپ، آیکون، یا رنگ‌بندی عوض بشه، بگو تا فایل‌ها رو ویرایش کنم.
